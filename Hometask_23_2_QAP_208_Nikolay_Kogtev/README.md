Задача:
Выгрузить с сайта https://batamebel.ru/product/krovati/?display=price в Excel файл список диванов с колонками:
1. Название
2. Длина, мм
3. Ширина, мм
4. Высота, мм
5. Цена

Необходимое ПО для работы программы:
1. OS Windows 10 (или выше)
2. PyCharm 2024.3 (Community Edition)
3. Microsoft Excel 2007 (или выше)
4. Текстовый редактор

Список файлов программы:
1. Hometask_23_2_QAP_208_Nikolay_Kogtev.py
2. README.md

*Корректная работа под другими OS и программами возможна, но не гарантируется корректное использование

Порядок действий:
1. Установить в PyCharm 2024.3 (Community Edition) следущие библиотеки:
1.1 pip install beautifulsoup4 lxml
1.2 pip install requests beautifulsoup4 pandas
2. Создать новую дирректорию в PyCharm 2024.3 с названием sofa_data (или любым удобным для Вас)
3. В дирректории sofa_data создать Python file с названием sofa_data.py (или любым удобным для Вас)
4. Скопировать код из файла Hometask_23_2_QAP_208_Nikolay_Kogtev.py в Python file с названием sofa_data.py (или с Вашим названием)
5. Запустить код и дождаться его выполнения
6. В дирректории sofa_data будет создан Excel файл с названием sofa_data.xlsx, по которому нужно сделать два клика мышкой
7. Если файл не читаемый, то нужно:
7.1 Нажать по нему правой кнопкой мышки, затем из всплывающего меню выбрать open in --> Explorer
7.2. Откроется проводник Windows, в котором нужно сделать два клика по файлу sofa_data.xlsx
